Versat is a high-level hardware compiler that automates the generation of
custom Coarse-Grained Reconfigurable Array (CGRA) accelerators. Written in
C++, Versat ingests a high-level graph specification of an algorithm,
written in the Versat specification language, and outputs a matching
hardware accelerator together with the software needed to drive it.
